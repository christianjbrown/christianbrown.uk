{%- comment -%} A real dialog rather than a floating box: it takes focus when it opens, keeps the tab key inside itself, hands focus back on close, and closes on Escape. Escape counts as declining, so dismissing it is a decision and it does not come back on the next page. It also ships hidden and is shown by JavaScript, rather than shipping visible and being hidden — so it is never a dead card on a page whose scripts failed to load. The English below is the build-time default. global.js rebuilds this paragraph from the resolved locale's catalogue before the dialog opens, reusing these two anchors, so the wording, the link labels and the button labels all follow the visitor's language. The ids are how it finds them. {%- endcomment %}
