* Original enamel pin badges, some raising money for a related charity.
* Static Jekyll storefront on GitHub Pages, with live sold counts pulled from Etsy and eBay by Cloud Run functions.
* Built and open-sourced the SDKs those functions use, for the [Etsy Open API](https://github.com/christianjbrown/etsy-open-api-sdk-php), [eBay Browse API](https://github.com/christianjbrown/ebay-browse-api-sdk-php) and [eBay Sell Fulfillment API](https://github.com/christianjbrown/ebay-sell-fulfillment-api-sdk-php).
